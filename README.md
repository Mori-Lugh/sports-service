Работают просмотр списка матчей, фильтр по сезону, поиск матча по номеру и добавление нового матча.

GET /matches — список матчей.
GET /matches?season_id=1 — матчи выбранного сезона.
GET /matches/{match_id} — отдельный матч.
POST /matches — добавление матча.

Данные хранятся в памяти и сбрасываются после перезапуска. Четыре автоматических теста прошли успешно.
