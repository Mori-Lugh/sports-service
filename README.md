Учебный сервис для работы с футбольными матчами.
Сейчас можно посмотреть матчи, отобрать их по сезону и добавить новый матч, расчет статистики будет уже потом

Создаем окружение и установить библиотеки:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```powershell
.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Проверка работы: http://127.0.0.1:8000/health

Страница для проверки запросов: http://127.0.0.1:8000/docs


- GET /health — проверить работу сервера.
- GET /matches — получить список матчей.
- GET /matches?season_id=1 — получить матчи выбранного сезона.
- GET /matches/{match_id} — получить матч по номеру.
- POST /matches — добавить новый матч.

При добавлении матч получает ответ 201.
Если номер уже занят, сервис возвращает 409.
Если данные неправильные — 422.
Если матч не найден — 404.

Установить библиотеки для тестов и запустить проверки:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверяются добавление матча, повтор номера, отрицательный счёт, фильтр по сезону и запрос несуществующего матча.

Команды и исходные матчи вымышленные, а данные хранятся в памяти и сбрасываются после перезапуска.
PostgreSQL, Redis и Kafka пока не подключены.
