# Sports Service — первый шаг

Самостоятельный учебный компонент спортивного приложения.
Его ответственность: данные матчей, результаты и спортивная статистика.
Пользовательские прогнозы и уведомления принадлежат соседнему сервису.

## Что работает сейчас

Приложение FastAPI и GET /health. Вход: HTTP-запрос без тела.
Выход: JSON {"status": "ok"}. Это проверка доступности приложения.

## Запуск на Windows

Нужен Python 3.11 или новее. Откройте терминал в папке сервиса:

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000/health и http://127.0.0.1:8000/docs.
Остановка сервера: Ctrl+C.

## Следующие шаги

Модели и тестовые матчи; затем расчёт статистики; затем формирование событий
по контракту sports-to-prediction.txt и подключение соседнего компонента.
На этом этапе PostgreSQL, Redis и Kafka ещё не подключены.

## Как подготовлен код

Этот стартовый код подготовлен с помощью ChatGPT. При добавлении в проект
участник проверяет запуск и разбирает назначение каждого файла.
Личные результаты проверки и вопросы следует записать после запуска.

## Что лежит в файлах

- main.py — приложение и адреса запросов.
- __init__.py — пустой файл, отмечает папку как пакет Python.
- requirements.txt — библиотеки для запуска.
- .gitignore — файлы, которые не нужно добавлять в Git.
