# Мой компонент: Sports Service

## Что он будет делать

Хранить факты о матчах и считать спортивную статистику.
Для первой версии беру футбол и вымышленные данные одного сезона.

## Пример сценария

Пользователь открывает список матчей, выбирает матч и смотрит результат.
Позже сможет посмотреть статистику команды за сезон.

## Вход и выход

Вход от сайта: запрос списка матчей, конкретного матча или статистики команды.
Выход для сайта: JSON с нужными данными.
Вход данных матчей: сначала тестовые данные и ручное добавление через API.
Позже потребуется выбрать настоящий источник данных.

## Связь с сервисом прогнозов

Sports будет передавать факты о матче: создание, начало, завершение,
отмену и исправление результата. Канал по предложенному контракту — Kafka.
Сейчас подключение ещё не сделано.
Поля команд и значение version нужно согласовать перед подключением.

## Где заканчивается моя ответственность

Sports знает матч и результат. Пользовательские прогнозы, их проверка
и уведомления — ответственность сервиса Prediction/Notify.

## Планы

1. Запустить приложение.
2. Добавить модели и API матчей.
3. Рассчитывать статистику по завершённым матчам.
4. Формировать события и соединиться с соседним сервисом.

## Ограничения прототипа

Данные будут храниться в памяти и сбрасываться при перезапуске.
База, авторизация, live и Kafka пока не подключены.
ML в этом компоненте пока нет. Место ML в общем проекте обсуждается командой.
